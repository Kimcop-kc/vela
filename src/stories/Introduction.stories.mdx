# Vela Design System

Vela 是一个 AI 深度驱动的小说创作 IDE，其 UI 设计系统基于 Tailwind CSS v4 + CSS 变量实现主题化。

> **设计令牌的唯一真源是 `src/index.css`。**
> 本页只做可视化展示，数值一律以 `src/index.css` 为准 —— 新增令牌请改那里，不要在本页复制一份。
> （曾有过一份 `src/tokens/` 的 TS 副本，因与真源脱节已删除。）

## Themes

Vela 支持 **5 套主题**，全部通过 `@layer base` 内的 CSS 变量实现；切换时只改根元素上的类名，组件无需感知。

| Theme | Class | Description | Preview |
|-------|-------|-------------|---------|
| `light` | `:root` | Fluent 2 浅色（默认） | <div style={{width: 60, height: 30, background: '#F5F5F5', border: '1px solid #D6D6D6', borderRadius: 4}} /> |
| `galaxy` | `.galaxy` | 深邃星空深色 | <div style={{width: 60, height: 30, background: '#171D26', border: '1px solid #2C3644', borderRadius: 4}} /> |
| `paper` | `.paper` | 温暖纸质感 | <div style={{width: 60, height: 30, background: '#F4F0E7', border: '1px solid #DCD5C8', borderRadius: 4}} /> |
| `dark` | `.dark` | VS Code 风格暗黑 | <div style={{width: 60, height: 30, background: '#1C1C1C', border: '1px solid #3C3C3C', borderRadius: 4}} /> |
| `ocean` | `.ocean` | 冷调深海 | <div style={{width: 60, height: 30, background: '#141B24', border: '1px solid #27323F', borderRadius: 4}} /> |

## Spacing

间距直接使用 Tailwind 的默认刻度（`1` = 4px 起步），不额外定义 CSS 变量。

| Class | Value | Usage |
|-------|-------|-------|
| `p-1` | 4px | 紧凑分组 |
| `p-2` | 8px | 组件内部默认间距 |
| `p-3` | 12px | 组件内边距 |
| `p-4` | 16px | 区块内边距 |
| `p-6` | 24px | 面板内边距 |

## Z-Index

层级常量见 `src/shared/z-index.ts`，与 `src/index.css` 的 `--z-*` 变量一一对应。
`modal` / `tooltip` / `toast` 三层必须走常量或对应变量，不得写字面量。

## Components

原子组件位于 `src/components/ui/`，共 21 个（Button / IconBtn / Input / Textarea / NativeSelect / Label / Switch / Badge / Tooltip / Dialog / AlertDialog / Confirm / Toast / ActionToast / EmptyState / ContextMenu / MenuItem / Icon / Skeleton / MarkdownContent / PostProcessStatusPanel）。
各组件用法见其对应的 story。
